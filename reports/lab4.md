### 1.在我们的easy-fs中，root inode起着什么作用？如果root inode中的内容损坏了，会发生什么？
根目录文件，作用是文件系统的入口点，通过root inode查看目录和文件构成的树，找到其他文件的inode。如果根目录文件损坏了，可能整个文件系统就无法访问，找不到其他文件的inode。

### 1. 举出使用 pipe 的一个实际应用的例子。

tips:

#### 想想你平时咋使用 linux terminal 的？
```
ps aux | grep "python"
```

用于查看正在运行的python进程，ps aux命令输出所有进程的信息，通过管道将输出传递给grep命令，grep命令过滤出包含"python"的行，从而显示出所有正在运行的python进程的信息，方便终止这个进程。

#### 如何使用 cat 和 wc 完成一个文件的行数统计？
```
cat Makefile | wc -l
```

### 2. 如果需要在多个进程间互相通信，则需要为每一对进程建立一个管道，非常繁琐，请设计一个更易用的多进程通信机制。
消息队列，每个进程可以将消息发送到一个公共的消息队列中，其他进程可以从这个队列中读取消息。

共享内存，每个进程可以将数据写入共享内存中，其他进程可以从共享内存中读取数据。
